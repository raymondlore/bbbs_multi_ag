# E2E 시나리오 1: 목록·검색·태그 필터·페이지네이션

기준: `docs/plan.md` 2절 '목록'. 사전 조건: 서버 실행(`uvicorn api.main:app --workers 1`), 브라우저로 `http://localhost:8000/#/` 접속. 과제 25건 이상 등록(태그 `챗봇`, `RAG` 포함), 그중 일부는 스크린샷 없음.

> 자동 점검 2026-11-14: Playwright(Chromium)로 서버 8887(시나리오 1~4)·8888(시나리오 5)을 띄워 실행했다. 결과 칸의 '통과/실패'는 그 결과이고, 괄호 안은 확인한 내용이다.

| # | 단계 | 기대 결과 | 결과 |
|---|---|---|---|
| 1 | 빈 DB 상태에서 `#/` 접속 | "아직 등록된 과제가 없습니다" 류의 빈 목록 안내와 첫 등록 유도 버튼 표시 | 통과 (아직 등록된 과제가 없습니다. 첫 과제를 등록해 보세요. 과제 등록) |

| 3 | 과제 25건 등록 후 목록 접속 | 최신 등록순으로 20개 표시, 카드에 제목·요약(150자)·작성자·태그 칩·등록일·썸네일 | 통과 (20건, 첫 카드=최신(스크린샷 있는 과제), 요약 -자) |

| 9 | `%` 또는 `_` 만 입력해 검색 | 와일드카드가 아니라 해당 문자가 실제 들어간 과제만 표시(없으면 '결과 없음') | 통과 (% → 할인 100% 계산기, _ → snake_case 변환기) |
| 10 | 존재하지 않는 단어 검색 | '결과 없음' 상태와 필터 초기화 버튼 표시 | 통과 |
