# E2E 시나리오 2: 과제 등록과 비밀번호 안내

기준: `docs/plan.md` 2절 '등록·수정', '비밀번호 안내'. 사전 조건: 서버 실행, `#/new` 접속.

| # | 단계 | 기대 결과 | 결과 |
|---|---|---|---|
| 1 | 목록의 [과제 등록] 클릭 | `#/new` 폼 표시(과제명, 설명, 배포 URL, 저장소 URL, 작성자, 태그, 스크린샷) | |
| 2 | 아무것도 입력하지 않고 제출 | 필수 항목 오류 안내, 입력값 유지, 서버 요청이 막히거나 422 메시지가 폼 상단에 표시 | |
| 3 | 과제명·설명·작성자만 입력하고 제출 | "배포 URL / 저장소 URL 중 하나 이상" 오류 표시 | |
| 4 | 설명 입력 중 글자 수 확인 | 글자수 표시가 실시간 갱신, 2000자 초과 시 경고 또는 제한 | |
| 5 | 배포 URL에 `javascript:alert(1)` 입력 후 제출 | URL 오류 표시(등록 안 됨) | |
| 6 | 태그 입력란에 `챗봇` 입력 후 Enter, `RAG` 입력 후 쉼표 | 각각 칩으로 추가되고 칩의 제거 동작 가능 | |
| 7 | 태그를 6개 이상 추가 시도 | 5개까지만 허용 또는 오류 안내 | |
| 8 | 태그에 `a<b` 입력 | 허용되지 않는 문자 안내 | |
| 9 | 스크린샷으로 png 선택 | 미리보기 표시, 제거 버튼으로 해제 가능 | |
| 10 | 2MB 초과 이미지 선택 후 제출 | 스크린샷 필드 옆에 크기 초과 메시지(413) | |
| 11 | gif 또는 svg 파일 선택 후 제출 | 스크린샷 필드 옆에 형식 불가 메시지(415) | |
| 12 | 정상 값(배포 URL 1개, 태그 2개, png)으로 제출 | 제출 중 버튼 비활성, 성공 시 비밀번호 안내 화면으로 전환 | |
| 13 | 비밀번호 안내 화면 확인 | 12자리 비밀번호, [복사] 버튼, "다시 볼 수 없고 분실 시 수정·삭제 불가" 경고 표시 | |
| 14 | [상세 보기] 상태 확인 | "보관했습니다" 체크 전에는 비활성 | |
| 15 | [복사] 클릭(http 환경 포함) | 복사 성공 안내, 실패하면 선택 가능한 읽기 전용 입력창으로 대체 | |
| 16 | 체크박스 선택 후 [상세 보기] | 상세 화면(`#/projects/{id}`)으로 이동 | |
| 17 | 상세에서 새로고침 후 뒤로가기로 안내 화면 복귀 시도 | 비밀번호가 다시 표시되지 않음(URL·localStorage·sessionStorage에도 없음: 개발자도구 확인) | |
| 18 | 이전 화면에서 서버 오류(서버 중지)로 제출 | 오류 메시지 표시, 입력값 유지 | |
| 19 | 모바일 폭에서 폼 사용 | 입력란이 화면 폭에 맞고 키보드로 모든 입력란 접근 가능 | |
