# E2E 시나리오 5: 오류 상태와 비밀번호 잠금

기준: `docs/plan.md` 2절 '비밀번호 오류 문구', `docs/api.md` 6절. 사전 조건: 과제 1건과 올바른 비밀번호 `PW`. 서버는 `TRUST_PROXY` 없이 실행(모든 접속이 같은 IP). 각 시나리오 전에 서버를 재시작하면 잠금이 초기화된다.

> 자동 점검 2026-11-14: Playwright(Chromium)로 서버 8887(시나리오 1~4)·8888(시나리오 5)을 띄워 실행했다. 결과 칸의 '통과/실패'는 그 결과이고, 괄호 안은 확인한 내용이다.

| # | 단계 | 기대 결과 | 결과 |
|---|---|---|---|
| 1 | 삭제 다이얼로그(또는 수정 저장)에서 틀린 비밀번호를 4회 입력 | 매번 "비밀번호가 일치하지 않습니다", 남은 횟수는 표시되지 않음 | 통과 (4회 모두 "비밀번호가 일치하지 않습니다.") |
| 2 | 5회째 틀린 비밀번호 입력 | 여전히 403 문구(5번째 실패까지는 일치 오류) | 통과 (비밀번호가 일치하지 않습니다.) |
| 3 | 6번째 시도(틀린 값) | "잠시 후(약 15분) 다시 시도" 문구(429), 가능하면 분 단위 표시, 입력란·버튼이 일시 비활성 | 통과 ("시도 횟수를 초과했습니다. 잠시 후(약 15분) 다시 시도하세요.", 입력칸·버튼 비활성) |
| 4 | 잠금 중 올바른 `PW`로 삭제·수정 시도 | 정답이어도 429 문구가 나오고 과제는 삭제·수정되지 않음 | 통과 (정답이어도 "시도 횟수를 초과했습니다. 잠시 후(약 15분) 다시 시도하세요.", 과제 그대로) |
| 5 | 다른 과제에서 올바른 비밀번호로 수정 | 해당 과제는 잠기지 않아 정상 저장 | 통과 (잠긴 과제는 정답도 429, 다른 과제는 정답으로 수정 저장 200 (응답을 기다려 다시 확인)) |
| 6 | 서버 재시작 후 같은 과제에 `PW`로 삭제 | 잠금이 풀려 삭제 성공(카운터는 메모리 방식) | 통과 (재시작 후 정답으로 삭제 성공) |
| 7 | 4회 틀린 뒤 올바른 `PW`로 수정 성공, 이후 다시 4회 틀림 | 성공 시 카운터가 초기화되어 잠기지 않음 | 통과 (4회 실패 → 정답 저장 성공 → 다시 4회 실패해도 잠기지 않음) |
| 8 | 존재하지 않는 과제 id(`#/projects/99999/edit`)에서 저장 | 404 안내 | 통과 (과제를 찾을 수 없습니다. 삭제되었거나 없는 과제입니다.) |
| 9 | 설명 2001자·제목 101자로 등록 | 해당 필드명이 포함된 422 메시지가 폼 상단에 표시 | 통과 (화면이 먼저 막음: "과제명은 100자 이내로 입력하세요." / "설명은 2000자 이내로 입력하세요.". 서버 직접 호출 422: "title: 100자 이하로 입력하세요.") |
| 10 | 존재하지 않는 해시 경로(`#/abc`) 접속 | 빈 화면이 아니라 안내 또는 목록으로 이동 | 통과 (페이지를 찾을 수 없습니다. 목록으로) |
| 11 | `http://localhost:8000/docs`, `/openapi.json` 접속 | 404(문서 화면 없음), 본문은 오류 JSON | 통과 (/docs 404 JSON, /openapi.json 404 JSON, /redoc 404 JSON) |
| 12 | `http://localhost:8000/api/v1/nope` 접속 | `{"error": {"code": "NOT_FOUND", ...}}` JSON | 통과 ({"error":{"code":"NOT_FOUND","message":"Not Found"}}) |
| 13 | 개발자도구 콘솔·네트워크 확인 | CSP 위반 경고 없음, 외부 도메인 요청 없음(폰트·CDN 포함) | 통과 (CSP 위반·스크립트 오류 0건, 외부 도메인 요청 0건) |
| 14 | 네트워크 차단(서버 중지) 상태에서 저장·삭제 | 입력값 유지된 채 오류 토스트/메시지 표시, 버튼 재활성화 | 통과 (저장: "서버에 연결할 수 없습니다. 잠시 후 다시 시도하세요."(입력 유지), 삭제: "서버에 연결할 수 없습니다. 잠시 후 다시 시도하세요.", 버튼 다시 사용 가능) |
