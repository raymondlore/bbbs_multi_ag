# E2E 시나리오 3: 과제 상세

기준: `docs/plan.md` 2절 '상세'. 사전 조건: 스크린샷 있는 과제, 없는 과제, 배포 URL만 있는 과제, 저장소 URL만 있는 과제가 있다.

> 자동 점검 2026-11-14: Playwright(Chromium)로 서버 8887(시나리오 1~4)·8888(시나리오 5)을 띄워 실행했다. 결과 칸의 '통과/실패'는 그 결과이고, 괄호 안은 확인한 내용이다.

| # | 단계 | 기대 결과 | 결과 |
|---|---|---|---|
| 1 | 목록에서 스크린샷 있는 과제 클릭 | `#/projects/{id}` 상세에 제목, 설명, 작성자, 태그, 등록일, 스크린샷 표시 | 통과 (#/projects/30) |
| 2 | 로딩 상태 확인 | 로딩 표시 후 내용 표시 | 통과 (응답을 2초 늦춰 확인) |
| 3 | 스크린샷 없는 과제 열기 | 스크린샷 영역 자체가 숨겨짐 | 통과 |
| 4 | 배포 URL만 있는 과제 | 저장소 URL 줄이 숨겨짐 | 통과 (작성자,배포 URL,등록일) |
| 5 | 링크 클릭 | 새 탭에서 열림(`rel="noopener noreferrer"` 확인) | 통과 (새 탭(http://127.0.0.1:8887/#/dep), rel="noopener noreferrer") |
| 6 | 존재하지 않는 id(`#/projects/99999`) 접속 | 404 상태("삭제되었거나 없는 과제")와 목록으로 이동 링크 | 통과 (과제를 찾을 수 없습니다. 삭제되었거나 없는 과제입니다. 목록으로) |
| 7 | 서버 중지 후 상세 새로고침 | 오류 상태 표시 | 통과 (API 연결 끊김 → "서버에 연결할 수 없습니다. 잠시 후 다시 시도하세요. 다시 시도" (1-18과 같은 방식)) |
| 8 | 설명에 줄바꿈이 있는 과제 | 줄바꿈이 유지되어 표시 | 통과 ("첫째 줄\r\n둘째 줄\r\n셋째 줄") |
| 9 | 제목·설명에 `<script>`·`<img onerror=...>` 포함 과제 | 문자 그대로 표시되고 스크립트 미실행 | 통과 (문자 그대로, 실행 없음) |
| 10 | [목록으로] 클릭 | 이전 검색·필터·페이지 상태의 목록으로 복귀 | 통과 (#/?tag=챗봇) |
| 11 | [수정], [삭제] 버튼 존재 확인 | 두 버튼이 보이고 비밀번호 입력 전에도 수정 화면은 열림 | 통과 (비밀번호 없이 수정 화면 열림) |
| 12 | 태블릿·모바일 폭 | 스크린샷이 폭을 넘지 않고 가로 스크롤 없음 | 통과 (375px:맞음, 768px:맞음) |
